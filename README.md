# Производственная практика (технологическая)

Решения практических кейсов 3, 4 и 5.

| Кейс | Папка | Что сделано |
|---|---|---|
| 3 | [Case3-Calculator](Case3-Calculator) | Калькулятор на Windows Forms (C#) |
| 4 | [Case4-Tetris](Case4-Tetris) | Тетрис, консольное приложение C# |
| 5 | [Case5-Unity](Case5-Unity) | Проект Unity: Cinemachine, анимация бонуса, монеты и кошелек, препятствия, частицы |

Кейсы 3 и 4 открываются в Visual Studio 2022 (нужен .NET 8), кейс 5 в Unity 2022.3 LTS.
